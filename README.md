# Камнелом / Kamnelom

Готовый к переносу исходный код пиксельной игры для свингов с гирей.
Экспорт: 28 октября 2026. Основное устройство пользователя: iPhone 13, Safari,
фронтальная камера. Язык интерфейса: русский.

## Быстрый старт

Нужен Node.js 18+ (пакет проверен на Node.js 24.22.1). Внешних зависимостей нет.
Из каталога с этим README:

```sh
npm run dev
```

Открой http://localhost:4173 на этом же компьютере.

```sh
npm test
npm run check
```

`npm install` не требуется. Исходники приложения уже лежат в `dist/`: это
редактируемые HTML/CSS/JS, а не сгенерированный результат сборки.

**На iPhone нужна HTTPS-ссылка.** HTTP-адрес компьютера в локальной сети обычно
не подходит для доступа к камере. Размести содержимое `dist/` на статическом
HTTPS-хостинге. Открытие `index.html` через `file://` не является поддерживаемым
способом проверки камеры. Локальный сервер привязан к 127.0.0.1.

## Перенос в новый репозиторий

1. Распакуй архив и скопируй содержимое папки `kamnelom/` в новый репозиторий.
2. Открой этот репозиторий в Codex.
3. Дай Codex прочитать `AGENTS.md` и `docs/CODEX_HANDOFF.md`.
4. Готовое первое задание находится в `docs/NEXT_TASK.md`.
5. Выполни `npm test`, затем запусти приложение командой выше.

Если репозиторий создаётся с нуля:

```sh
git init
git add .
git commit -m "Import Kamnelom prototype and handoff"
```

Новый git remote выбери самостоятельно. Архив не привязан к прежнему хостингу.

## Что внутри

- `dist/` — вся актуальная игра, камера, проверка свинга, графика и звук.
- `tests/` — четыре автономных набора тестов.
- `tools/` — локальный статический сервер и запуск проверок без зависимостей.
- `docs/CODEX_HANDOFF.md` — требования, архитектура, выполненная работа, ограничения.
- `docs/NEXT_TASK.md` — готовое задание на улучшение распознавания.
- `docs/RECOGNITION_RESEARCH.md` — исследование MediaPipe, MoveNet, Apple Vision.
- `docs/TEST_PLAN.md` — сценарии проверки на настоящем телефоне.
- `docs/PROVENANCE.md` — версии, опубликованные ссылки, происхождение файлов.
- `history/front-camera-onboarding.patch` — изменения от первой версии игры к текущей.
- `reference/strumok/` — исходники и тест первоначальной игры с гребным тренажёром.
- `SHA256SUMS.txt` — контрольные суммы всех файлов пакета, кроме самого списка.

## Состояние продукта

Работают: пиксельный гном и валун, удары, трещины, осколки, звук по кнопке,
демо, таймер, пауза, счётчик, фронталка, зеркальное превью, пробный свинг,
зелёный сигнал перед запуском, красный сигнал при неудаче и повторная проверка.
20 засчитанных свингов разрушают один валун.

**Распознавание пока экспериментальное и по отзыву пользователя ненадёжно.**
В текущей версии используется самописный optical flow, а не нейросеть позы.
MediaPipe, MoveNet и Apple Vision НЕ подключены. Успешные синтетические тесты
не подтверждают точность реальных свингов на iPhone.

Серверной части, базы данных, аккаунтов, записи видео, аналитики, моделей ML
и синхронизации с телевизором в коде нет. Графика рисуется Canvas 2D; звук
синтезируется Web Audio. Дополнительные картинки, аудиофайлы и ключи API не нужны.
Авторизация через ChatGPT на старом адресе обеспечивается хостингом, а не кодом;
на новом хостинге она автоматически не появится.
