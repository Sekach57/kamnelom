# Готовое первое задание для Codex

Прочитай README.md, AGENTS.md, docs/CODEX_HANDOFF.md и docs/RECOGNITION_RESEARCH.md.
Продолжи Камнелом: пользователь жалуется на ненадёжный подсчёт свингов с гирей.
Используется iPhone 13, Safari, фронтальная камера, телефон перед человеком.

Замени самописный optical flow моделью позы. Начни с MediaPipe Pose Landmarker;
проверь актуальную документацию и совместимость выбранной фиксированной версии.
Сначала получи работающее отображение плеч, локтей, запястий и таза на видеокадре,
а затем подключай игровой счётчик. Сохрани текущую пиксельную игру.

Требования:
1. Понятная загрузка модели и явная ошибка с повтором, если она не загрузилась.
2. Фронтальная камера, зеркальный preview и правильно совмещённый overlay точек.
3. Калибровка по трём пробным свингам с понятным прогрессом 1/3, 2/3, 3/3.
4. Высота рук относительно тела, нормализация по размеру корпуса, сглаживание,
   пороги входа/выхода и полный цикл: верх → низ → верх.
5. При неуверенных/потерянных ключевых точках не угадывать удар. Жёлтая подсказка,
   сброс неполного цикла после длительной потери. Учитывать перекрытие запястий.
6. Успех зелёный, затем автостарт; неудача красная с конкретной подсказкой и повтором.
7. Пробные свинги не считаются игровыми. Один полный свинг = один удар.
8. Обработка локально. Никакой записи/отправки видео и микрофона.
9. Измерять время inference и число реально обработанных кадров; не накапливать
   очередь устаревших кадров. Worker рассмотреть и проверить на Safari.
10. Сохранить отмену, освобождение камеры, паузу при фоне, сброс и демо.

Проверь npm test и npm run check. Адаптируй тесты под позовые координаты: нормальные
циклы, неполный цикл, джиттер, выпадение рук, неверная уверенность, пауза, смена
положения камеры. Добавь локальный режим проверки записанного видео без загрузки
на сервер, если это нужно для воспроизводимой оценки.

Не заявляй улучшенную точность без сравнения на реальных размеченных видео.
В финале раздели: что реализовано, что проверено автоматически и что ещё нужно
испытать на iPhone. Не публикуй в старый Sites-проект; работаем в новом репозитории.
