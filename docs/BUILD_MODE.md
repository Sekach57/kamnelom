# Режим «Стройка» (спецификация, НЕ реализовано)

Статус: решения согласованы с владельцем, кода пока нет. Реализованное и предложенное не смешивать.
Существующий режим «Валун» остаётся без изменений; «Стройка» добавляется рядом отдельным режимом.

## Идея

Упражнения помогают гному строить. Игрок свободно переключает занятие; ничего не идёт по жёсткой цепочке.

| Занятие | Упражнение | Повторов | Что происходит |
|---|---|---|---|
| Копать | свинг | по материалу (см. ниже) | блок материала попадает в кучу у горы |
| Тащить | отжимание | 5 на блок | блок переезжает из кучи у горы в кучу на стройке |
| Строить | приседание | 20 на блок | гном ставит блок по чертежу |

Две кучи (буферы): «у горы» и «на стройке». Копать можно сколько угодно. Тащить доступно, только если куча
у горы не пуста. Строить доступно, только если куча на стройке не пуста и в чертеже есть клетки.
Недоступное занятие показывается серым с причиной («Нечего тащить, сначала покопай»), а не молча не работает.
Прогресс внутри блока (например 6 из 10 свингов) сохраняется при переключении занятия.

## Материалы (прочность = сколько свингов копать один блок)

Числа стартовые, для настройки баланса; на реальных тренировках не проверены.

| Материал | Свингов на блок |
|---|---|
| Щебень | 4 |
| Песчаник | 6 |
| Кирпич | 8 |
| Камень | 10 |
| Мрамор | 16 |
| Обсидиан | 25 |

Все материалы доступны сразу. Тащить (5) и ставить (20) от материала не зависят. Материал не влияет на очки
лидерборда: очки идут по повторам с весами упражнений (приседание 1, свинг 2, отжимание 3), как сейчас.

## Формы (стартовый набор)

| Форма | Блоков | Заметка |
|---|---|---|
| Блок | 1 | |
| Ступени | 1 | направление вправо или влево |
| Дверь | 2 | 1 клетка в ширину, 2 в высоту |

Форма выбирается при планировании, а не при добыче: в куче лежат «блоки материала». Стоимость формы в приседаниях
равна числу блоков × 20 (дверь = 40). Плиты, колонны, окна и т. д. добавляются позже строкой в конфиге.

## Планирование

- Чертёж рисуется заранее, между подходами, бесплатно: клетки-«призраки» с материалом и формой.
- В режиме «Строить» гном сам достраивает призраки по очереди (по умолчанию снизу вверх), пока хватает блоков.
- Нет нужного материала для призрака: гном берёт следующий доступный и пишет, чего не хватает.
- Готовое можно разбирать: блок возвращается в кучу на стройке бесплатно, без упражнений.
- Физики и обязательной опоры нет: можно строить в воздухе.

## Модель данных (предложение)

- `materials`: id → { название, палитра, повторов на добычу }.
- `shapes`: id → { название, блоков, размер в клетках }.
- Мир: разреженная карта `"x,y" → { material, shape, facing }`, призраки: то же с флагом `planned`.
- Состояние: `pileMountain`, `pileSite` (по материалам), текущая работа, прогресс текущего блока, версия схемы.
- Хранение: `localStorage`, версионированный JSON, чтение в try/catch. Видео и координаты тела не хранятся.

## Ограничения проекта (AGENTS.md), которые сохраняются

- Фронтальная камера, зеркальное превью, калибровка перед игрой, красный и зелёный сигналы, повтор.
- Пробные повторы калибровки не идут в счёт, мир и очки.
- Первая смена на каждое упражнение: полная калибровка (3 пробных повтора). Повторная смена на уже откалиброванное:
  облегчённая проверка (положение + 1 пробный повтор). Требует подтверждения владельца.
- При смене занятия `detector.reset()` и кадры не обрабатываются на время перехода (перекладывание телефона).
- Отжимания требуют телефон на полу, остальное стоя: на экране перехода показывать подсказку положения.
- Очистка камеры, отмена запроса, пауза при уходе в фон работают и при смене занятия.
- Точность распознавания на iPhone не измерена; ручные «+1 / −1» остаются для проверки. Старый optical flow не возвращать.
- Нет записи видео, загрузок, аналитики, платных сервисов; микрофон выключен.

## Этапы

1. Чистая логика `dist/build.js` + `tests/build.cjs` (материалы, формы, кучи, чертёж, доступность занятий).
2. Сцена (гора, поле, площадка, блоки разных материалов) и демо с ручными повторами, без камеры.
3. Редактор чертежа.
4. Подключение детекторов и переходов между занятиями.
5. Сохранение мира.
6. Серверные очки (схему менять не нужно: повторы уже идут по упражнениям); позже «построено блоков».
7. Группы и удалённый режим (телефон и экран): отдельно, позже. Общая стройка группы продолжает «Башню Камнелома».
